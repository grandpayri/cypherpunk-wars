[MAN_01] OPERATIONAL_GUIDE

Turns

Each turn is a real Kaspa transaction, spent from your covenant-locked Gameplay Vault (see Command Center > Phish). The network itself enforces what a turn can pay for -- not a client-side counter.

Plain Wallet vs. Gameplay Vault

Your Plain Wallet holds ordinary TKAS, spendable however you like. Your Gameplay Vault is a Toccata covenant: funds there can only leave via a real CPW-tagged transaction, never a free-form send -- see the Transfer page's demo of the network rejecting a non-compliant spend.

$PUNKW (War Chest)

Earned by Phishing. Every Genesis and Phish transaction writes your current $PUNKW total directly into that transaction's on-chain payload -- a real state snapshot, not just a log message -- so the sidebar's War Chest total reflects what's actually recorded on-chain for that action.

Sectors[PLANNED]

Built by spending $PUNKW, making your Phishing more efficient. The economy for this (Phase 6) isn't built yet -- the sidebar currently shows a fixed starting value, not a real purchase.

Units, Items & DOS Attacks[PLANNED]

Later phases add unit types (daemons/processes run on the network), items, and DOS payloads operators can cast against each other -- including Armageddon, a covenant-verifiable season-ending reset. None of this exists yet; see Attack and Research for current status.
