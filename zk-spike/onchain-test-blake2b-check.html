ZK Spike: Confirm JS blake2b(32) Matches Kaspa's On-Chain OpBlake2b

Minimal, cheap test: a tiny covenant that pushes a fixed piece of data, hashes it with OpBlake2b, and compares against a hash pre-computed in JS via the `blake2b` npm package (32-byte output, no key -- matching Kaspa's `Params::new().hash_length(32)`). If this succeeds, the VK-hash covenant pattern is safe to build on top of. No ZK proof involved -- this isolates JUST the hash-matching question.
